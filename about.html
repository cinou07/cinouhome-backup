The Cinou engine

Why Cinou always answers.

  1. Your messageModel + effort chosen in the picker
  2. RouterMaps the Cinou model to the best upstream model
  3. Key rotationRate-limited keys cool down; the next key is used
  4. Provider fallbackOpenAI → Groq → Gemini → OpenRouter → free
  5. TimeoutsEvery call has a deadline — no endless spinner
  6. AnswerReturned to the app or your API client

“Unlimited” means Cinou itself never counts credits or caps messages. Upstream providers you configure can still apply their own limits; the engine works around them by rotating keys and providers.

● C1 Coder · high effort
function debounce(fn, ms = 300) {
  let t;
  return (...a) => { clearTimeout(t); t = setTimeout(() => fn(...a), ms); };
}

FAQ

      
Is Cinou AI really free and unlimited?
Yes inside the app: no credits, no message caps, no paywalled models. The server uses a keyless free provider by default, and owners can add their own provider keys for more speed and capacity.

      
What are Apex, C1, Spark and C Lite?
They are Cinou's model tiers. Each is routed to a suitable upstream model and tuned with its own system prompt and default effort.

      
What happens if a provider is down?
The engine times out the call and moves to the next key or provider automatically, so you get an answer or a clear error — never an endless wait.

      
Is my data private?
Chats are stored in your browser and, if you sign in, synced to your account. API keys are stored hashed. Messages are sent to the AI provider that answers them.

      
Is Cinou affiliated with Claude, OpenAI or Manus?
No. Cinou AI is an independent project; its design is inspired by modern assistants but its code is its own.
